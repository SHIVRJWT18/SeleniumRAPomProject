# Selenium + Rest Assured Automation Framework

## 📌 Project Overview

This project is a Hybrid Automation Testing Framework developed using Java, Selenium WebDriver, Rest Assured, TestNG, and Maven.

It supports both Web UI Automation and REST API Automation within a single Maven-based project. The framework follows the Page Object Model (POM) design pattern and modular architecture to improve code reusability, maintainability, and scalability.

## 🚀 Key Features

### 1. Selenium Web UI Automation
- Automates web application functionality using Selenium WebDriver.
- Implements Page Object Model (POM) design pattern.
- Supports multiple locator strategies.
- Supports cross-browser testing.

### 2. REST API Automation
- Automates REST APIs using Rest Assured and Java.
- Implements API request and response logging.
- Uses Java POJO classes to create API request payloads.
- Passes dynamically generated data and response values between API requests.
- Validates updated and retrieved resource details.

### 3. TestNG Integration
- Uses TestNG for test execution and test management.
- Implements TestNG annotations and assertions.
- Supports test prioritization and dependency management.
- Organizes test execution through TestNG XML suites.

### 6. Dynamic Test Data
- Uses Java Faker to generate dynamic test data.
- Maintains reusable test data utilities.

### 7. Maven Build Management
- Uses Maven for project and dependency management.
- Maintains dependencies in `pom.xml`.

### 8. Version Control and Reporting
- Supports Allure reporting when configured.
- Uses Git for source code management.
